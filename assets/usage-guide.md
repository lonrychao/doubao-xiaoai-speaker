# 小爱音箱接入豆包 · 配置与使用说明

> 设备：小爱音箱 Pro（LX06）｜ 模型：豆包（火山方舟）｜ 方案：MiGPT（不拆机、不刷机、免费开源）

---

## 一、先搞清楚"免唤醒"到底能免到什么程度

小米音箱靠本地「唤醒词」触发收音，这是硬件机制，**任何方案都无法做到"永远不喊唤醒词"**。

MiGPT 能做的是**连续对话**：

| 场景 | 你要做的 |
|---|---|
| 进入连续对话 | 说一次：**「小爱同学，召唤豆包」** |
| 进入后连续提问 | **直接说话，不用再喊"小爱同学"**，一句接一句 |
| 结束对话 | 说「退出豆包」，或停止说话 60 秒自动退出 |

这就是"不要每次都唤醒"——**喊一次，之后连续聊**。

---

## 二、文件清单

| 文件 | 作用 |
|---|---|
| `.env` | 豆包 API 配置（密钥和接入点） |
| `.migpt.js` | 小米账号 + 音箱型号 + 连续对话参数 |
| `start-windows.bat` | Windows 一键启动 |
| `start-linux.sh` | Mac / Linux / 树莓派一键启动 |

> 前两个是隐藏文件（点开头），在文件管理器开启"显示隐藏文件"即可看到。**不要改文件名。**

---

## 三、启动前准备（3 件事）

1. **电脑和音箱连同一个 WiFi**。
2. **装 Docker**：Windows/Mac 装 [Docker Desktop](https://www.docker.com/products/docker-desktop/)；Linux 执行 `curl -fsSL https://get.docker.com | sh`。
3. **小米账号关掉两步验证**（登录小米账号 → 安全设置 → 关闭二次验证），否则 MiGPT 无法登录。

---

## 四、启动步骤

### Windows
双击 `start-windows.bat`，首次会自动下载镜像（约 1–2 分钟），看到"**启动成功！**"即可。

### Mac / Linux / 树莓派
```bash
cd 到本文件夹所在目录
chmod +x start-linux.sh
./start-linux.sh
```

### 验证是否跑通
```bash
docker logs -f mi-gpt
```
看到 `MiGPT 启动成功` 且无红色报错即成功。按 `Ctrl+C` 退出日志查看（服务仍在后台运行）。

## 五、日常使用

| 你想做什么 | 对音箱说 |
|---|---|
| 单次问豆包 | 「小爱同学，**请** 帮我写一首诗」 |
| 单次问豆包 | 「小爱同学，**你** 知道相对论吗」 |
| 单次问豆包 | 「小爱同学，**豆包** 解释一下光伏发电」 |
| 进入连续对话（免唤醒） | 「小爱同学，**召唤豆包**」 |
| 连续对话中提问 | 直接说，不用喊唤醒词 |
| 退出连续对话 | 「退出豆包」或「再见」 |

> 进入连续对话后，**等豆包说完、顶部指示灯亮起再开口**，中途插话它听不见。

## 六、常见问题排查

| 症状 | 原因 | 解决 |
|---|---|---|
| 报 `70016 登录验证失败` | 密码错 / userId 填了手机号 | 核对纯数字小米ID和密码；关两步验证 |
| 提示异地登录风控 | 账号在陌生 IP 登录 | 用**和跑 MiGPT 同一台电脑**的浏览器登录一次小米账号，过验证后约 1 小时重试 |
| 报"找不到设备" | 音箱名称与米家不一致 | 核对米家APP名称，注意**有没有空格**；仍不行把 `.migpt.js` 里 `enableTrace` 改 `true`，重启后从日志找 `miotDID` 数字填进 `did` |
| 有回答但音箱**不出声** | TTS 指令不对 | 按型号查 ttsCommand |
| 回答到一半中断 | 播放状态检测异常 | 把 `checkTTSStatusAfter` 从 3 调到 5 |
| **响应偏慢** | seed-pro 会先"深度思考" | 换 flash 模型接入点（见下方①） |

---

## 七、安全提醒 ⚠️

1. `.migpt.js` 存有**小米账号明文密码**，配置文件**不要外传**、不要发到群里。
2. 建议跑通后**把小米密码改回/改掉**，不影响已运行的 MiGPT。
3. 豆包 API Key **不要泄露**，否则会被别人消耗额度。

---

## 八、进阶优化

### ① 响应慢 → 换不思考的 flash 模型
1. 火山方舟 → 在线推理 → 新建接入点，模型选 **`doubao-seed-1.6-flash`**。
2. 把新接入点 ID 填进 `.env` 的 `OPENAI_MODEL=`，重启容器。

### ② 改豆包的人设/名字
编辑 `.migpt.js` 的 `bot.name` 和 `bot.profile`，保存后重启容器。

### ③ 以后换树莓派 / NAS 常开
这套 `.env` + `.migpt.js` 直接拷过去，装好 Docker 跑 `start-linux.sh` 即可，不用重新配置。开机自启已由 `--restart unless-stopped` 保证。

### ④ 关于"自定义唤醒词 / 完全免唤醒"
需要刷机方案（Open-XiaoAI），有变砖和失保风险，**不建议家用**。
