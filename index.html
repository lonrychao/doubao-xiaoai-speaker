先说清「免唤醒」的真相

小米音箱靠本地唤醒词触发收音，这是硬件机制，任何方案都无法做到「永不喊唤醒词」。

本方案实现的是「喊一次，连续聊」：

场景你要做的
进入连续对话说一次「小爱同学，召唤豆包」
进入后连续提问直接说话，不用再喊「小爱同学」
结束对话说「退出豆包」，或停止说话 60 秒自动退出

三步配置

获取豆包密钥

打开火山方舟 → 创建 API Key 和推理接入点（模型选 doubao-seed-1.6-flash）。

填写配置

复制 assets/ 下的模板，替换占位符：.env 填豆包密钥，.migpt.js 填小米账号和音箱名称。

一键启动

Windows 双击 start-windows.bat，Mac/Linux 运行 start-linux.sh，或用 Docker：

docker run -d --name mi-gpt \
  --env-file $(pwd)/.env \
  -v $(pwd)/.migpt.js:/app/.migpt.js \
  --restart unless-stopped \
  idootop/mi-gpt:latest
